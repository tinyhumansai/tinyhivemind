# basic_hive package

The `release` hive: Alice (`planner`) and Bob (`reviewer`) on a read-only,
ephemeral-workspace runtime. The routing policy restates the thresholds the
retired manifest format defaulted to. See the [package index](../README.md).

| File | Purpose |
| --- | --- |
| `hive.json` | Seats, desk, policies and runtime, in canonical form |
| `constitution.json` | Default caps: 60 turns, width 8 |
| `memory.json` | Memory root; no identities or bindings |
| `roles/` | `planner` and `reviewer` charters, the routing descriptions |
| `seats/` | Alice's and Bob's prompts |
| `context/` | Release notes no seat composes; see its README |
