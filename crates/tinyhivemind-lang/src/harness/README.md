# Harness kinds

`HarnessKind`: the harnesses a package may name, and their wire names. The
`harnesses` section, the capability table and the diagnostics of the
[harness spec](../../../../docs/specs/harnesses.md) are not here yet.

| File | Purpose |
| --- | --- |
| `mod.rs` | The type. |
| `test.rs` | Pins the wire names. |
