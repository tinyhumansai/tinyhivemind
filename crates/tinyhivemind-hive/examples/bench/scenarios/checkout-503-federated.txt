# The checkout-503 hidden profile, split across three channels.
#
# `checkout-503.txt` puts five members in one room and hides the answer in a
# conjunction no member holds alone. This is the same incident with the same
# answer, and one thing changed: the members are on three desks that cannot
# read each other's transcripts.
#
# That change is the whole experiment. In one room the conjunction is reachable
# by deliberating — every fact is one turn away. Here it is not reachable at
# all unless somebody asks another channel, because the four facts that make
# #pool the answer are held on three different desks:
#
#   - the pool caps at 20                              (Data)
#   - a request holds a connection for its whole life  (Platform)
#   - in-flight requests have sat at 24-31 since 09:14 (Platform)
#   - the release quintupled how long each one lasts   (Release)
#
# Platform holds two of the four and can get no further alone. Data holds the
# cap and cannot see the in-flight count. Release holds the multiplier and
# nothing to multiply.
#
# The first version of this file failed as an experiment, and the way it failed
# is worth keeping. It gave Data both "the cap is 20" and "the database would
# accept 400", which is very nearly the answer written down: two of the three
# desks solved it without asking anybody anything, and the run proved nothing
# about crossing a channel. A desk that can reach the truth alone is not part
# of a hidden profile.
#
# So each desk now also holds a fact that points confidently at a *different*
# wrong option, and each of those decoys is refuted only by a fact on another
# desk:
#
#   - Platform reads doubled concurrency after an SDK release as a retry storm.
#     Only Release knows the retry path has never been switched on.
#   - Data reads an eighteen-month-old cap that carried yesterday's traffic as
#     exonerated. Only Release knows each request now holds its connection five
#     times longer.
#   - Release reads pod CPU at 85% as a capacity shortfall. Only Platform knows
#     replicas do not add connections.
#
# Every desk can rule something out by itself. No desk can rule #pool in.

truth: pool

[option pool]
Raise the database connection pool cap from 20 to 60.

[option retries]
Flip off the retry-on-timeout path SDK 4.2 shipped.

[option scale]
Triple the API replica count.
